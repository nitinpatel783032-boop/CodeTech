HTML Tutorial

HTML (HyperText Markup Language) — web ka bunyaad. Zero se HTML Pro bano!

1. HTML Kya Hota Hai?

HTML ek Markup Language hai jo web pages ka structure banati hai. Browser HTML padhta hai aur screen pe dikhata hai.

HTML ≠ Programming Language. Isme loops/conditions nahi hote — sirf content ka structure hota hai. Logic ke liye JavaScript hai!
HTML ka simple example
<h1>Yeh ek Heading hai</h1>
<p>Yeh ek Paragraph hai.</p>
<a href="page.html">Yeh ek Link hai</a>
<img src="photo.jpg" alt="Photo">

2. Environment Setup

HTML ke liye sirf 2 cheezein chahiye:

Best Setup:
✅ VS Code — code.visualstudio.com (free)
✅ Google Chrome — DevTools ke saath
✅ VS Code Extension: Live Server — file save karo, browser auto-refresh
Pehla file banao — 5 steps
Step 1: VS Code open karo
Step 2: File → New File → "index.html" naam do
Step 3: Yeh code type karo:

<!DOCTYPE html>
<html>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>

Step 4: Ctrl+S se save karo
Step 5: File ko Chrome mein open karo
→ "Hello World!" dikh jayega! 🎉

3. HTML Basic Structure

Har HTML file ka ek standard template hota hai — yeh hamesha use karo:

html — Complete Template
<!DOCTYPE html>         <!-- HTML5 declaration -->
<html lang="hi">          <!-- Root element -->

  <head>                  <!-- Browser ke liye info (hidden) -->
    <meta charset="UTF-8">   <!-- Hindi text support -->
    <meta name="viewport"
          content="width=device-width">
    <title>Page ka Naam</title>   <!-- Browser tab title -->
  </head>

  <body>                  <!-- Yeh sab screen pe dikhega -->
    <h1>Meri Website</h1>
    <p>Namaste Duniya!</p>
  </body>

</html>                   <!-- Root element band -->

5. Attributes

Attributes tags ko extra information dete hain — hamesha opening tag mein name="value" format mein.

html — Saare Common Attributes
id    → unique name (JS/CSS ke liye)
<h1 id="main-title">Title</h1>

class → styling ke liye (kai elements pe)
<p class="highlight bold">Text</p>

style → inline CSS
<p style="color:red;font-size:20px">Red</p>

href  → links ka destination
<a href="https://google.com">Google</a>

src   → image/script source
<img src="photo.jpg" alt="Photo">

target → link kahan khule
<a href="url" target="_blank">Naye tab</a>

title → hover tooltip
<p title="Yeh tooltip hai">Hover karo</p>

placeholder, required, disabled (forms)
<input type="text" placeholder="Naam" required>
<button disabled>Kaam nahi karega</button>

width, height (images/tables)
<img src="img.jpg" width="300" height="200">

6. Headings — h1 se h6

HTML mein 6 levels ki headings hain. h1 = page ka main title (ek page mein sirf ek!), h6 = sabse chhota.

SEO Rule: Ek page mein sirf ek <h1> hona chahiye. Google is heading ko sabse zyaada importance deta hai!

8. Links — <a> Tag

Anchor tag se hyperlinks banate hain. href = destination.

html — Sab Types ke Links
<!-- 1. Bahari website -->
<a href="https://google.com" target="_blank">Google</a>

<!-- 2. Apna dusra page -->
<a href="about.html">About Page</a>

<!-- 3. Same page ka section -->

10. Id & Class — Pehchaan ka Fark

id aur class dono attributes hain jo HTML elements ko CSS/JS se target karne ke liye use hote hain — lekin dono ke rules alag hain.

Ek line mein yaad rakho:
id = unique naam (sirf ek element per page)  |  class = group naam (kai elements share kar sakte hain)
html — Id vs Class Syntax
══════════════════════════════════════════
  ID  —  UNIQUE (ek page mein sirf EK baar)
══════════════════════════════════════════
<h1 id="main-title">Welcome!</h1>

CSS mein  →  # (hash)
#main-title { color: red; }

JS mein   →  getElementById [call karne ka tarika js part]
document.getElementById("main-title").style.color = "blue";

══════════════════════════════════════════
  CLASS  —  REUSABLE (kai elements pe)
══════════════════════════════════════════
<p class="highlight">Para 1</p>
<p class="highlight">Para 2</p>   ← same class, dono style ho gaye!
<span class="highlight">Span</span>

CSS mein  →  . (dot)
.highlight { background: yellow; }

JS mein   →  querySelectorAll
document.querySelectorAll(".highlight").forEach(el => ...);

══════════════════════════════════════════
  EK ELEMENT PE MULTIPLE CLASSES
══════════════════════════════════════════
<button class="btn btn-primary large">Click</button>
                ↑              ↑      ↑
             3 classes — space se alag karo

══════════════════════════════════════════
  ID + CLASS DONO EK ELEMENT PE
══════════════════════════════════════════
<div id="hero" class="section animated">...</div>
Id vs Class — Fark Ek Nazar Mein
┌─────────────────┬──────────────────┬──────────────────────┐
│  Feature        │    id            │    class             │
├─────────────────┼──────────────────┼──────────────────────┤
│  Uniqueness     │  Page mein SIRF  │  Kai elements pe     │
│                 │  EK baar         │  use kar sako        │
├─────────────────┼──────────────────┼──────────────────────┤
│  CSS selector   │  #myId           │  .myClass            │
├─────────────────┼──────────────────┼──────────────────────┤
│  JS selector    │  getElementById  │  querySelectorAll    │
│                 │  querySelector   │  getElementsByClass  │
├─────────────────┼──────────────────┼──────────────────────┤
│  Multiple?      │  Ek element pe   │  Ek element pe kai   │
│                 │  SIRF ek id      │  classes ho sakti    │
├─────────────────┼──────────────────┼──────────────────────┤
│  URL anchor?    │  Haan! #section  │  Nahi                │
│                 │  mein use hota   │                      │
├─────────────────┼──────────────────┼──────────────────────┤
│  Specificity    │  Zyaada powerful │  Kam powerful        │
│  (CSS priority) │  (100 points)    │  (10 points)         │
└─────────────────┴──────────────────┴──────────────────────┘
Common Galti: Ek page mein same id do baar mat do!
<div id="box"> aur <div id="box"> — yeh WRONG hai!
JavaScript sirf pehle wale ko pakdega. Aise kaam ke liye class use karo.

12. Tables

Tables se data rows aur columns mein organize karte hain.

html — Table Tags
<table>           Table container
  <thead>         Header section
    <tr>          Table Row
      <th>Naam</th>  Header cell (bold auto)
      <th>Age</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Rahul</td>  Data cell
      <td>22</td>
    </tr>
  </tbody>
  <tfoot>         Footer section
    <tr>
      <td colspan="2">Total</td> colspan merges columns
    </tr>
  </tfoot>
</table>

15. Semantic HTML5

Semantic tags content ka meaning batate hain. <div> ke bajaye meaningful tags use karo — SEO aur accessibility dono improve hote hain!

html — Complete Semantic Structure

  <nav>Navigation Menu</nav>
</header>

  <section>      Related content group
    <h2>Products</h2>

    <article>     Self-contained content (blog post)
      <h3>Product Title</h3>
      <p>Description</p>
    </article>

  </section>

  <aside>         Sidebar (related but secondary content)
    <h3>Related Links</h3>
  </aside>

16. Meta Tags

Meta tags <head> mein hote hain — browser aur search engines ke liye info. Users ko nahi dikhte!

html — Saare Important Meta Tags
<head>
  <!-- Zaruri (hamesha rakho) -->
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>Page Title — Site Name</title>

  <!-- SEO ke liye -->
  <meta name="description"
        content="HTML CSS JS seekhne ki website">
  <meta name="keywords"
        content="HTML, CSS, JavaScript">
  <meta name="author" content="CodeMaster">
  <meta name="robots" content="index, follow">

  <!-- Open Graph (WhatsApp/Facebook share) -->
  <meta property="og:title"   content="CodeMaster">
  <meta property="og:description" content="...">
  <meta property="og:image"   content="thumbnail.jpg">
  <meta property="og:url"     content="https://site.com">

  <!-- Twitter Card -->
  <meta name="twitter:card"    content="summary_large_image">
  <meta name="twitter:title"   content="CodeMaster">

  <!-- Favicon (browser tab icon) -->
  <link rel="icon" href="favicon.ico">

  <!-- CSS file -->
  <link rel="stylesheet" href="style.css">

  <!-- Auto redirect (5 sec baad) -->
  <meta http-equiv="refresh" content="5;url=new-page.html">

  <!-- Theme color (mobile browser) -->
  <meta name="theme-color" content="#0a0e1a">
</head>

17. Audio & Video

HTML5 mein native audio/video support hai — koi Flash nahi chahiye!

html — Audio, Video, iframe
<!-- VIDEO ELEMENT -->
<video
  width="640" height="360"
  controls             play/pause/volume buttons
  autoplay             automatically start
  muted                autoplay ke liye zaruri
  loop                 baar baar chalao
  poster="thumb.jpg"   thumbnail image
  preload="auto">
  <source src="video.mp4"  type="video/mp4">
  <source src="video.webm" type="video/webm">
  Browser video support nahi karta.
</video>

<!-- AUDIO ELEMENT -->
<audio controls loop>
  <source src="song.mp3" type="audio/mpeg">
  <source src="song.ogg" type="audio/ogg">
</audio>

<!-- YOUTUBE embed (iframe) -->
<iframe
  src="https://www.youtube.com/embed/VIDEOID"
  width="560" height="315"
  frameborder="0"
  allowfullscreen>
</iframe>

<!-- Google Maps embed -->
<iframe
  src="https://maps.google.com/maps?q=Delhi&output=embed"
  width="400" height="300">
</iframe>
