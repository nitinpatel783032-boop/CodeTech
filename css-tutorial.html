CSS Tutorial

CSS (Cascading Style Sheets) se websites ko sundar aur attractive banate hain — colors, layouts, animations sab CSS se!

CSS Kya Hota Hai?

HTML structure banata hai, CSS usse style deta hai. Bina CSS ke website plain text ki tarah dikhti hai — CSS se woh khubsoorat banti hai.

css — Pehla CSS Code 
/* Yeh ek CSS comment hai */
body {
  background-color: #0a0e1a;
  color: #e2e8f0;
  font-family: sans-serif;
}

h1 {
  color: #264de4;
  font-size: 2rem;
  text-align: center;
}
CSS 3 tarike se lagaya ja sakta hai: Inline (style attribute), Internal (<style> tag), External (.css file). External best practice hai!

Selectors — Elements Ko Target Karo

Selector batata hai ki CSS kaunse element pe lagegi. Teen main types hain:

css — Selectors 
/* Element Selector - sare <p> ko target karo */
p {
  color: #94a3b8;
}

/* Class Selector - .classname */
.highlight {
  background: yellow;
  padding: 4px 8px;
}

/* ID Selector - #idname (ek baar use karo) */
#main-title {
  font-size: 2.5rem;
  font-weight: bold;
}

/* Multiple selectors ek saath */
h1, h2, h3 {
  font-family: 'Arial', sans-serif;
}

/* Child Selector - direct child */
nav > ul {
  list-style: none;
}

/* Descendant Selector - koi bhi andar wala */
div p {
  margin: 0;
}

/* Attribute Selector */
input[type="text"] {
  border: 2px solid #264de4;
}
Specificity Rule: ID > Class > Element. Agar conflict ho to zyada specific selector jeetta hai!

Colors & Backgrounds

CSS mein color alag-alag tarike se diya ja sakta hai. Backgrounds mein solid color se lekar gradient tak sab kuch ho sakta hai!

css — Colors 
/* Color ke 4 tarike */
.box1 { color: red; }                     /* Named */
.box2 { color: #264de4; }               /* Hex */
.box3 { color: rgb(38, 77, 228); }      /* RGB */
.box4 { color: rgba(38, 77, 228, 0.5); }/* RGBA (alpha=transparency) */
.box5 { color: hsl(225, 71%, 52%); }    /* HSL */

/* Background Color */
.card {
  background-color: #0f1526;
}

/* Linear Gradient */
.hero {
  background: linear-gradient(135deg, #264de4, #00d4ff);
}

/* Radial Gradient */
.circle-bg {
  background: radial-gradient(circle, #a855f7, #0a0e1a);
}

/* Background Image */
.banner {
  background-image: url('image.jpg');
  background-size: cover;       /* poora cover karo */
  background-position: center;  /* center mein rakho */
  background-repeat: no-repeat; /* repeat mat karo */
}

Text & Fonts — Typography

CSS se text ki har cheez customize kar sakte ho — font, size, weight, spacing, decoration sab!

css — Text Properties 
p {
  /* Font family */
  font-family: 'Roboto', Arial, sans-serif;

  /* Font size */
  font-size: 1rem;      /* 1rem = 16px */

  /* Font weight */
  font-weight: 400;     /* 100-900, ya bold/normal */

  /* Font style */
  font-style: italic;   /* italic ya normal */

  /* Text color */
  color: #e2e8f0;

  /* Text alignment */
  text-align: center;   /* left, right, center, justify */

  /* Line height (readability) */
  line-height: 1.6;

  /* Letter spacing */
  letter-spacing: 0.05em;

  /* Text decoration */
  text-decoration: underline; /* none, underline, line-through */

  /* Text transform */
  text-transform: uppercase; /* lowercase, capitalize */

  /* Text shadow */
  text-shadow: 2px 2px 8px rgba(38,77,228,0.6);
}

Box Model — CSS ka Dil

Har HTML element ek box hai. Box model mein 4 parts hote hain: Content, Padding, Border, Margin.

css — Box Model 
.box {
  /* Content ki width/height */
  width: 200px;
  height: 100px;

  /* Padding - content ke andar ka space */
  padding: 20px;           /* sab taraf */
  padding: 10px 20px;      /* top/bottom  left/right */
  padding-top: 10px;

  /* Border - box ki line */
  border: 2px solid #264de4;
  border-radius: 8px;      /* rounded corners */

  /* Margin - box ke bahar ka space */
  margin: 20px;
  margin: 0 auto;           /* center karo */

  /* box-sizing: ek important trick! */
  box-sizing: border-box;  /* padding/border width mein count ho */
}

Display & Position

display property control karti hai element kaise dikhta hai. position batata hai element page pe kahan hoga.

css — Display 
/* Display Values */
.block    { display: block; }        /* Full width leta hai (div, p, h1) */
.inline   { display: inline; }       /* Text ke saath flow (span, a) */
.iblock   { display: inline-block; } /* Inline + width/height set kar sako */
.hidden   { display: none; }         /* Bilkul hide kar do */
.flex-box { display: flex; }         /* Flexbox container */
.grid-box { display: grid; }         /* Grid container */
css — Position 
/* position: static (default) - normal flow */
.normal { position: static; }

/* position: relative - apni jagah se thoda hato */
.moved {
  position: relative;
  top: 10px;
  left: 20px;
}

/* position: absolute - parent ke hisab se position */
.tooltip {
  position: absolute;
  top: 0;
  right: 0;
}

/* position: fixed - scroll karo, yeh wahi rahega */
.navbar {
  position: fixed;
  top: 0;
  width: 100%;
  z-index: 999;  /* oopar dikhao */
}

/* position: sticky - scroll karte karte chipak jaye */
.sidebar {
  position: sticky;
  top: 20px;
}

Flexbox — Layout ka Jaadu

Flexbox se items ko row ya column mein easily arrange kar sakte ho. Modern layouts ke liye must-know!

css — Flexbox 
.container {
  display: flex;             /* flex start */
  flex-direction: row;       /* row ya column */
  justify-content: center;  /* horizontal align */
  align-items: center;      /* vertical align */
  gap: 1rem;               /* space between */
  flex-wrap: wrap;         /* wrap to next line */
}

.item {
  flex: 1;                  /* equal space lega */
  align-self: flex-start;  /* sirf is item ki alignment */
}

/* justify-content values: */
/* flex-start | flex-end | center */
/* space-between | space-around | space-evenly */

CSS Grid — 2D Layout Power

CSS Grid se rows aur columns dono mein layout banate hain. Flexbox ek direction mein kaam karta hai, Grid dono mein!

css — CSS Grid 
.grid-container {
  display: grid;

  /* 3 columns define karo */
  grid-template-columns: 1fr 1fr 1fr;       /* 3 equal */
  grid-template-columns: 200px auto 200px;  /* fixed + auto */
  grid-template-columns: repeat(3, 1fr);     /* shorthand */

  /* Rows define karo */
  grid-template-rows: 80px auto 60px;

  /* Gap between cells */
  gap: 16px;                    /* row aur column dono */
  column-gap: 20px;
  row-gap: 12px;
}

/* Item ko multiple columns span karo */
.header {
  grid-column: 1 / 4;    /* column 1 se 4 tak (3 columns) */
}
.sidebar {
  grid-row: 2 / 4;       /* 2 rows span karo */
}

/* Auto-fill - jitni fit ho utni columns */
.card-grid {
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
}

Pseudo-classes & Pseudo-elements

Pseudo-classes kisi element ki special state ko target karti hain (hover, focus, etc). Pseudo-elements elements ka ek part style karte hain.

css — Pseudo-classes 
/* :hover — mouse le jao pe */
button:hover {
  background: #264de4;
  transform: scale(1.05);
}

/* :focus — input pe click/tab karo */
input:focus {
  outline: none;
  border-color: #264de4;
  box-shadow: 0 0 0 3px rgba(38,77,228,0.3);
}

/* :active — click ho raha hai */
button:active { transform: scale(0.95); }

/* :nth-child — kaunsa baccha */
li:nth-child(odd)  { background: rgba(255,255,255,0.03); }
li:nth-child(2)    { color: #00d4ff; }
li:first-child     { font-weight: bold; }
li:last-child      { border-bottom: none; }

/* :not() — in elements ko chhod do */
button:not(.primary) { opacity: 0.6; }

/* Pseudo-elements — :: double colon */
p::first-line  { font-weight: bold; }
p::first-letter{ font-size: 2rem; float: left; }
div::before    { content: "★ "; color: #f7df1e; }
div::after     { content: " ✓"; color: #00ff88; }

CSS Animations

@keyframes se custom animations banate hain. animation property se element pe lagate hain.

css — Animations 
/* Step 1: @keyframes se animation define karo */
@keyframes slideIn {
  0%   { transform: translateX(-100px); opacity: 0; }
  100% { transform: translateX(0); opacity: 1; }
}

/* Step 2: Element pe lagao */
.card {
  animation: slideIn 0.5s ease-out forwards;
/*            name    duration  timing  fill-mode */
}

/* Animation properties alag se */
.box {
  animation-name:            bounce;
  animation-duration:        1.5s;
  animation-timing-function: ease-in-out;
  animation-iteration-count: infinite; /* ya koi number */
  animation-direction:       alternate; /* forwards, backwards */
  animation-delay:           0.3s;      /* start mein wait */
}

/* Transition (hover pe smooth change) */
.btn {
  transition: all 0.3s ease;
}
.btn:hover {
  transform: translateY(-3px);
  box-shadow: 0 10px 30px rgba(38,77,228,0.4);
}

CSS Variables (Custom Properties)

CSS Variables se ek jagah color ya value define karo aur poori site mein use karo. Theming ke liye perfect!

css — Variables 
/* Variables :root mein define karo */
:root {
  --primary: #264de4;
  --secondary: #00d4ff;
  --bg: #0a0e1a;
  --text: #e2e8f0;
  --radius: 12px;
}

/* Phir var() se use karo */
.btn {
  background: var(--primary);
  color: var(--text);
  border-radius: var(--radius);
}

/* Fallback value bhi de sakte ho */
.card {
  background: var(--card-bg, #0f1526); /* agar --card-bg nahi to #0f1526 */
}

/* JS se bhi change kar sakte ho! */
// document.documentElement.style
//   .setProperty('--primary', '#a855f7');
Pro Tip: CSS Variables se dark/light mode bana sakte ho sirf kuch lines ke saath. JavaScript se document.documentElement.style.setProperty('--bg', '#fff') karke theme change karo!

Responsive Design — Har Screen Pe Acha Dikho

Responsive design matlab website mobile, tablet, desktop — sab pe acha dikhe. Iske liye Media Queries use karte hain.

css — Media Queries 
/* Mobile First Approach (recommended!) */
/* Pehle mobile ke liye likho */
.container {
  width: 100%;
  padding: 16px;
  font-size: 1rem;
}

/* Tablet (768px se bada) */
@media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }
  .grid {
    grid-template-columns: 1fr 1fr; /* 2 columns */
  }
}

/* Desktop (1024px se bada) */
@media (min-width: 1024px) {
  .container { max-width: 1200px; }
  .grid      { grid-template-columns: repeat(3, 1fr); }
}

/* Common Breakpoints */
/* xs: 480px, sm: 768px, md: 1024px, lg: 1280px, xl: 1536px */

/* Dark mode detect karo! */
@media (prefers-color-scheme: dark) {
  :root { --bg: #0a0e1a; --text: #e2e8f0; }
}

/* Fluid Typography */
h1 { font-size: clamp(1.5rem, 5vw, 3rem); }
/* min 1.5rem, max 3rem, 5vw viewport width ke hisaab se */
