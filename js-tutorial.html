JavaScript Tutorial

JavaScript se web pages interactive bante hain — buttons, animations, forms, sab JS se life mein aate hain!

JavaScript Kya Hota Hai?

HTML structure deta hai, CSS design deta hai, aur JavaScript behaviour deta hai. Click pe kuch ho, form validate ho, data fetch ho — sab JS karta hai.

JS browser mein directly run hoti hai — koi server ki zarurat nahi. console.log() se output dekho browser ke DevTools mein (F12).
javascript — Hello World 
// Yeh ek JavaScript comment hai
console.log("Hello, World!");

// Alert box dikhao
alert("Namaste, CodeMaster!");

// HTML mein text badlo
document.getElementById("title").innerHTML = "JS Magic! ✨";

Variables — Data Store Karo

Variables mein data store karte hain. JS mein teen keywords hain: var, let, let.

javascript — Variables 
// let - change ho sakta hai
let naam = "Rahul";
naam = "Priya";  // OK ✅

// let - change nahi hoga
let PI = 3.14159;
// PI = 3; → Error! ❌

// var - purana tarika (use mat karo)
var age = 20;

// Different data types
let number  = 42;           // Number
let text    = "Hello";      // String
let isTrue  = true;         // Boolean
let nothing = null;         // Null
let arr     = [1, 2, 3];   // Array
Note: Aaj ke time mein var use karna avoid karo. Hamesha let ya let use karo — ye more predictable hain.

Data Types — Kitne Tarah Ka Data?

JavaScript mein 8 data types hain — 7 Primitive aur 1 Object. typeof operator se type pata karte hain.

javascript — Data Types 
// 1. Number — integers aur decimals dono
let age  = 25;
let price = 99.99;
let inf  = Infinity;
let nan  = NaN;         // Not a Number

// 2. String — text, quotes mein
let name  = "Rahul";
let city  = 'Delhi';

console.log(name.length);    // 5
console.log(name.toUpperCase()); // RAHUL

// 3. Boolean — sirf true ya false
let isLoggedIn = true;
let hasError   = false;

// 4. Undefined — variable define, value nahi
let x;
console.log(x); // undefined

// 5. Null — intentionally khali
let user = null;

// 6. Symbol — unique identifier
let id = Symbol("id");

// 7. BigInt — bahut bade numbers
let big = 9007199254740991n;

// 8. Object — key-value pairs
let person = { naam: "Priya", age: 22 };

console.log(typeof age);      // "number"
console.log(typeof name);     // "string"
console.log(typeof isLoggedIn); // "boolean"

Boolean(0)    // → false (0, "", null, undefined = falsy)
Boolean(1)    // → true
parseInt("3.9")  // → 3
parseFloat("3.9") // → 3.9

Operators — Operations Karo

Operators se calculations, comparisons aur logic karte hain.

javascript — Operators 
// ===== Arithmetic Operators =====
let a = 10, b = 3;
console.log(a + b);  // 13 (addition)
console.log(a - b);  // 7  (subtraction)
console.log(a * b);  // 30 (multiplication)
console.log(a / b);  // 3.33 (division)
console.log(a % b);  // 1  (remainder/modulo)
console.log(a ** b); // 1000 (power: 10^3)
a++;  // a = 11 (increment)
b--;  // b = 2  (decrement)

// ===== Assignment Operators =====
let x = 10;
x += 5;   // x = x + 5 = 15
x -= 3;   // x = x - 3 = 12
x *= 2;   // x = x * 2 = 24
x /= 4;   // x = x / 4 = 6
x **= 2;  // x = x ** 2 = 36

// ===== Comparison Operators =====
console.log(5 == "5");   // true  (loose, type ignore)
console.log(5 === "5");  // false (strict, type check) ← HAMESHA YEH USE KARO
console.log(5 !== 3);   // true
console.log(10 > 5);    // true
console.log(10 <= 10);  // true

// ===== Logical Operators =====
console.log(true && false); // false (AND - dono true ho)
console.log(true || false); // true  (OR - koi ek true ho)
console.log(!true);         // false (NOT)

// ===== Ternary Operator =====
let score = 75;
let result = score >= 50 ? "Pass ✅" : "Fail ❌";
// condition ? agar true : agar false

// ===== Nullish Coalescing (??) =====
let name = null;
console.log(name ?? "Guest"); // "Guest" (null/undefined ho to default)

// ===== String Concatenation =====
console.log("Hello" + " " + "World"); // "Hello World"
console.log("Age: " + 25);             // "Age: 25"

If/Else — Decisions Lena

Condition check karke alag-alag code run karte hain.

javascript — If/Else & Switch 
// If / else if / else
let marks = 85;

if (marks >= 90) {
  console.log("A+ Grade 🏆");
} else if (marks >= 75) {
  console.log("A Grade ✅");
} else if (marks >= 60) {
  console.log("B Grade 👍");
} else {
  console.log("Fail ❌");
}
// Output: A Grade ✅

// Switch Statement — ek value, kai cases
let day = "Monday";
switch(day) {
  case "Monday":
    console.log("Sapte ka pehla din 😴");
    break;
  case "Friday":
    console.log("Weekend aane wala hai! 🎉");
    break;
  default:
    console.log("Normal din 📅");
}

Loops — Baar Baar Karo

Loops se ek kaam baar baar karte hain bina code repeat kiye.

javascript — Loops 
// For loop - fixed times
for (let i = 0; i < 5; i++) {
  console.log("Count: " + i);
}
// Output: 0, 1, 2, 3, 4

// While loop - jab tak condition true
let count = 0;
while (count < 3) {
  console.log("Hello #" + count);
  count++;
}

// Do...While - ek baar toh chalega hi
let num = 10;
do {
  console.log(num);  // 10 print hoga, phir condition check
  num++;
} while (num < 10);

// Array ke sath loops
let fruits = ["Apple", "Mango", "Banana"];

// forEach - har item pe function chalao
fruits.forEach((fruit, index) => {
  console.log(index, fruit);
});

// for...of - clean syntax
for (let fruit of fruits) {
  console.log(fruit);
}

// for...in - object keys ke liye
let user = { name: "Rahul", age: 25 };
for (let key in user) {
  console.log(key + ": " + user[key]);
}

// break - loop se baahar niklo
// continue - is iteration skip karo
for (let i = 0; i < 10; i++) {
  if (i === 5) break;      // 5 pe rok do
  if (i % 2 === 0) continue; // even skip
  console.log(i);           // 1, 3
}

Functions — Reusable Code Blocks

Functions ek kaam ko baar baar karne ka tarika hai — ek baar likho, hazaar baar use karo!

javascript — Functions 
// 1. Function Declaration
function greet(naam) {
  return `Namaste, ${naam}! 👋`;
}
console.log(greet("Rahul")); // Namaste, Rahul! 👋

// 2. Function Expression
let add = function(a, b) {
  return a + b;
};

// 3. Arrow Function (ES6) — modern & short
let multiply = (a, b) => a * b;  // one-liner
let square   = n => n * n;        // ek param, bracket optional
let sayHi    = () => "Hi! 👋";   // koi param nahi

// 4. Default Parameters
function power(base, exp = 2) {
  return base ** exp;
}
console.log(power(3));    // 9 (exp=2 default)
console.log(power(3, 3)); // 27

// 5. Rest Parameters (...args)
function sum(...nums) {
  return nums.reduce((total, n) => total + n, 0);
}
console.log(sum(1, 2, 3, 4)); // 10

// 6. Higher Order Functions
let nums = [1, 2, 3, 4, 5];
let doubled  = nums.map(n => n * 2);      // [2,4,6,8,10]
let evens    = nums.filter(n => n % 2 === 0); // [2,4]
let total    = nums.reduce((s, n) => s + n, 0); // 15

// 7. Closure — function ke andar function
function counter() {
  let count = 0;
  return () => ++count;  // inner function count access kar sakti hai
}
let inc = counter();
console.log(inc()); // 1
console.log(inc()); // 2

Arrays — Data ki List

Array ordered list hoti hai. Square brackets [] mein values hoti hain. Index 0 se shuru hota hai.

javascript — Arrays 
// Array banana
let fruits = ["Mango", "Apple", "Banana"];

// Access karo (index 0 se shuru)
console.log(fruits[0]);     // "Mango"
console.log(fruits.length); // 3

// CRUD Operations
fruits.push("Orange");      // End mein add karo   → [Mango,Apple,Banana,Orange]
fruits.pop();               // End se hatao       → [Mango,Apple,Banana]
fruits.unshift("Grapes");  // Start mein add     → [Grapes,Mango,Apple,Banana]
fruits.shift();             // Start se hatao     → [Mango,Apple,Banana]

// Kya hai andar?
console.log(fruits.includes("Mango"));  // true
console.log(fruits.indexOf("Apple"));   // 1

// Useful Array Methods
let nums = [3, 1, 4, 1, 5, 9, 2];
nums.sort((a, b) => a - b);          // [1,1,2,3,4,5,9]
nums.reverse();                       // ulta
let sliced = nums.slice(1, 4);      // index 1 to 3 copy
let joined = fruits.join(" | ");    // "Mango | Apple | Banana"

// Functional Methods
let doubled = nums.map(n => n * 2);
let big     = nums.filter(n => n > 3);
let sum     = nums.reduce((acc, n) => acc + n, 0);
let found   = nums.find(n => n > 4);  // pehla match
let allBig  = nums.every(n => n > 0); // sab true?
let anyBig  = nums.some(n => n > 8);  // koi ek true?

// Spread — array copy/merge
let a = [1, 2], b = [3, 4];
let merged = [...a, ...b]; // [1,2,3,4]

Objects — Real-World Data Model

Object mein related data ek jagah store karte hain — key-value pairs ke roop mein. JS mein almost sab kuch object hai!

javascript — Objects 
// Object banana
let person = {
  naam:    "Rahul",
  age:     25,
  city:    "Delhi",
  isActive: true,
  skills:  ["HTML", "CSS", "JS"],  // array andar bhi

  // Method — object ke andar function
  greet() {
    return `Hi, main ${this.naam} hoon!`;
  }
};

// Access karna — 2 tarike
console.log(person.naam);         // Dot notation
console.log(person["age"]);       // Bracket notation
console.log(person.greet());      // Method call
console.log(person.skills[0]);   // "HTML"

// Add / Update / Delete
person.email  = "rahul@email.com";  // add new key
person.age    = 26;                   // update
delete person.isActive;               // delete key

// Object Methods
console.log(Object.keys(person));   // ["naam","age","city",...]
console.log(Object.values(person)); // ["Rahul",26,"Delhi",...]
console.log(Object.entries(person));// [["naam","Rahul"],...]

// Destructuring
let { naam, age, city = "Mumbai" } = person;

// Object Spread — copy/merge
let updated = { ...person, age: 27, country: "India" };

// Array of Objects (common pattern)
let users = [
  { id: 1, naam: "Rahul", role: "admin" },
  { id: 2, naam: "Priya", role: "user"  },
];
let admins = users.filter(u => u.role === "admin");

Events — User Actions Handle Karo

Events tab fire hote hain jab user kuch karta hai — click, keypress, scroll, form submit, etc. addEventListener se handle karte hain.

javascript — Events 
// addEventListener — recommended tarika
let btn = document.getElementById("myBtn");
btn.addEventListener("click", (event) => {
  console.log("Button click hua!", event);
});

// Common Event Types
el.addEventListener("click",      handler); // click
el.addEventListener("dblclick",   handler); // double click
el.addEventListener("mouseover",  handler); // hover start
el.addEventListener("mouseout",   handler); // hover end
el.addEventListener("keydown",    handler); // key dabao
el.addEventListener("keyup",      handler); // key choro
el.addEventListener("input",      handler); // input change
el.addEventListener("submit",     handler); // form submit
el.addEventListener("scroll",     handler); // scroll
el.addEventListener("load",       handler); // page load

// Event Object properties
el.addEventListener("click", (e) => {
  console.log(e.target);      // kaunsa element click hua
  console.log(e.clientX, e.clientY); // mouse position
  e.preventDefault();          // default action rok do (form reload, etc)
  e.stopPropagation();          // bubble mat karo
});

// Keyboard events
document.addEventListener("keydown", (e) => {
  console.log("Key:", e.key, "Code:", e.code);
  if (e.key === "Enter") console.log("Enter dabaya!");
});

// Event Delegation — ek parent pe sab children handle karo
document.getElementById("list").addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    e.target.classList.toggle("selected");
  }
});

Async/Await — Asynchronous Code

JavaScript single-threaded hai lekin async code se network requests, timers, etc. ko non-blocking tarike se handle karta hai.

javascript — Async/Await 
// Async function - await ke liye zaruri
async function getData() {
  try {
    // await lagaao — result aane tak ruko
    let response = await fetch('https://api.example.com/data');

    // Response ko JSON mein convert karo
    let data = await response.json();

    console.log(data);

  } catch (error) {
    console.error('Error:', error);
  } finally {
    console.log('Done!'); // hamesha chalega
  }
}
getData();

// setTimeout — delay ke baad kaam karo
setTimeout(() => {
  console.log("2 second baad!");
}, 2000);

// setInterval — baar baar karo
let timer = setInterval(() => {
  console.log("Har second!");
}, 1000);
clearInterval(timer); // rok do

// Promise.all — kaafi requests ek saath
async function fetchAll() {
  let [users, posts] = await Promise.all([
    fetch('https://jsonplaceholder.typicode.com/users').then(r => r.json()),
    fetch('https://jsonplaceholder.typicode.com/posts').then(r => r.json()),
  ]);
  console.log(users.length, posts.length);
}
Pro Tip: Hamesha try/catch use karo async functions ke saath — network errors silently fail ho sakte hain warna!

Fetch API — Real Data Laao

fetch() se real APIs se live data la sakte ho. JSONPlaceholder ek free practice API hai.

javascript — Fetch API Complete 
// GET Request — data laao
async function getUsers() {
  let res  = await fetch('https://jsonplaceholder.typicode.com/users');
  let data = await res.json();
  return data;
}

// POST Request — data bhejo
async function createPost(postData) {
  let res = await fetch('https://jsonplaceholder.typicode.com/posts', {
    method:  'POST',
    headers: { 'Content-Type': 'application/json' },
    body:    JSON.stringify(postData)
  });
  return await res.json();
}

// Response status check
let res = await fetch('...');
if (!res.ok) throw new Error(`HTTP Error: ${res.status}`);
